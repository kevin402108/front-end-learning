CSS特性

继承性

子级默认继承父级的文字控制属性
e.g.

h3 label

p label

span label
div label
Hyper Link label

层叠性

相同属性会覆盖，不同属性会叠加

优先级

当一个标签使用了多种选择器时，基于不同种类的选择器的匹配规则

公式：通配符选择器 < 标签选择器 < 类选择器 < id选择器 < 行内样式 < !important

  • 选中标签的范围越大，优先级越低
  • !important 提权功能，提高权重到最高

叠加计算规则

叠加计算：如果是复合选择器，则需要权重叠加计算。

公式：（每一级之间不存在进位）

规则：

  • 从左向右依次比较选个数，同一级个数多的优先级高，如果个数相同，则向后比较
  • !important 权重最高
  • 继承权重最低
